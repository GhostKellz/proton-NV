# Architecture

Proton-NV is a build system, not an application. It assembles a custom Proton
distribution from upstream sources plus NVIDIA-focused patches and packages it
as a Steam compatibility tool.

## Build Flow

```
configure.sh ──► Makefile (generated) ──► Makefile.in
                                              │
        ┌─────────────────┬──────────────────┼──────────────────┐
        ▼                 ▼                  ▼                  ▼
      fetch ──────────► patch ──────────► build ──────────► dist ──► install
   clone upstream   apply patches/     compile Proton     package as     copy to
   into upstream/   onto upstream/     (+ DXVK, vkd3d,    Steam tool in  compat-
                                        dxvk-nvapi)        dist/         tools.d/
```

Each stage is gated by a stamp file (`.fetched`, `.patched`, `.built`, `.dist`)
so reruns are incremental.

## Directory Layout

```
proton-NV/
├── configure.sh          # generates Makefile; sets versions, driver/GPU targets
├── Makefile.in           # all build rules (fetch/patch/build/dist/install/...)
├── Makefile              # generated by configure.sh (do not edit)
├── proton                # launcher entrypoint referenced by toolmanifest.vdf
├── proton-nv.conf        # default runtime environment, copied into the dist
├── proton-nv.install     # pacman post-install messaging
├── PKGBUILD              # Arch package build
├── patches/              # patch sets applied during the patch stage
│   ├── nvidia/           # driver / scheduler / descriptor-heap detection
│   ├── proton/           # Proton + Wine patches
│   ├── dxvk/             # DXVK patches
│   ├── vkd3d/            # vkd3d-proton patches (currently in deprecated/)
│   └── wine-hotfixes/    # targeted Wine hotfixes
├── benchmark/            # MangoHud-based DX12 benchmarking tools
└── archive/              # reference implementations
```

Generated at build time (git-ignored):

```
upstream/   # cloned Proton, dxvk, vkd3d-proton, dxvk-nvapi
build/      # compilation output
dist/       # packaged Steam compatibility tool
```

## Upstream Components

`make fetch` clones, by the refs from `configure.sh`:

| Component | Upstream |
|-----------|----------|
| Proton | `ValveSoftware/Proton` |
| DXVK | `doitsujin/dxvk` |
| vkd3d-proton | `HansKristian-Work/vkd3d-proton` |
| dxvk-nvapi | `jp7677/dxvk-nvapi` |

The actual compilation is delegated to Proton's own `configure.sh` / `make dist`
after patches are applied; Proton in turn builds the bundled DXVK, vkd3d-proton,
and dxvk-nvapi.

## Packaging

The `dist` stage copies Proton's `build/dist/` output and generates the Steam
metadata (`toolmanifest.vdf`, `compatibilitytool.vdf`, `version`) plus a
`proton-nv/` directory holding `proton-nv.conf`. The result is a self-contained
compatibility tool ready to drop into `compatibilitytools.d/`.

## Configuration Surfaces

- **Build time:** `configure.sh` flags / environment → generated `Makefile` →
  `Makefile.in` (see [Build Options](../reference/build-options.md)).
- **Runtime:** `proton-nv.conf` defaults, overridable by
  `~/.config/proton-nv/config` and Steam launch options (see
  [Configuration](../getting-started/configuration.md)).
